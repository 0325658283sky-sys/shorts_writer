# 핸드오프: New Cut v2 — 템플릿 중심 흐름 · 편집기 확장 · 소스별 프로세스

## 개요
New Cut(쇼츠 생성기)의 **2차 상품화 설계**입니다. 1차 핸드오프(`design_handoff_newcut_productization`, 1~9단계, 브랜치 `sky_cut`, 최종 커밋 `1a9c5fe`)가 끝난 상태에서 이어집니다.

핵심 방향:
- **프로세스는 New Cut 고유 흐름을 발전시킵니다.** 블로그 생성기(Ditodio) 흐름을 복제하지 않고 비주얼 토큰만 공유합니다.
- 알파컷·피카클립에서 3가지를 가져옵니다: **① 점수 매긴 구간 후보 여러 개 중 고르기 ② 템플릿 갤러리를 독립 단계로 ③ 완료 화면에서 SNS 예약 업로드**.
- 사용자 요청 우선순위: **템플릿이 가장 중요**, 그다음 **편집기 옵션**(나레이션 TTS·배경음악·구간 편집·텍스트 효과·크기·폰트).
- **소스 4종(유튜브·MP4·블로그·상품)은 서로 다른 앞단 플로우**를 거치고, 템플릿·편집기·완료 화면은 공유합니다.

## 디자인 파일에 대해
`mockup/쇼츠 생성기 UX 개선 검토.dc.html`은 **HTML로 만든 디자인 참고 자료**입니다. 그대로 배포하는 코드가 아닙니다. 할 일은 이 디자인을 **기존 코드베이스**(`frontend/` React + Vite + TS, `styles.css`의 `:root` 토큰, `backend/` FastAPI + SQLite, `remotion/`)의 패턴대로 **다시 구현하는 것**입니다. 파일은 브라우저에서 바로 열립니다. `support.js`가 같은 폴더에 있어야 합니다.

목업은 섹션 번호(①~⑨-f)로 나뉘어 있습니다. 이 README는 같은 번호를 씁니다.

## 완성도
**중간 완성도(mid-fi)입니다.** 레이아웃·정보 구조·카피·상태·위계는 확정안입니다. 색·radius·그림자는 기존 `styles.css` 토큰이 기준입니다(목업 값은 토큰과 거의 같지만 **목업 쪽 radius 12–18px는 무시하고** `--radius: 11px`, `--radius-control: 8px`를 쓰세요). 회색 사각형은 전부 이미지·영상 자리 표시입니다.

## ⚠️ 코드와 목업이 다른 곳 — 코드 기준으로 정정
구현 전에 꼭 읽으세요. 목업 작성 뒤 코드를 확인하면서 발견한 차이입니다.

1. **① 소스 선택:** 목업은 소스 카드 4개를 그렸지만, 1차 8단계에서 이미 **URL 입력창 하나 + 자동 판별 배지 + MP4 드래그&드롭**으로 바뀌었습니다(`CreateStudio.tsx`). **현재 구현을 유지하세요.** 목업의 4카드는 "판별 결과 배지" 영역을 크게 보여준 것으로 해석하면 됩니다.
2. **⑨-e 요금 수치:** 목업의 "스탠다드 15 / 프리미엄 30 / 엔터프라이즈 60회", "라이트 월 1회"는 Ditodio 가격 참고 이미지 기준이라 **틀렸습니다.** 실제 코드(`usage_service.py` `PLAN_POLICIES`, `membershipPlans.ts`)는 **Free 쇼츠 3 · Lite 20 · Pro 80 /월**이고, 블로그 포스트 한도(15/60/200)는 **허브에서 따로** 관리합니다. 아래 "⑨-e 크레딧" 절의 표를 기준으로 삼으세요.
3. **⑤ 편집기 탭:** 목업은 우측 패널 5탭(텍스트·나레이션·배경음악·구간편집·전체 스타일)입니다. 현재 코드는 `MediaPanel`이 3탭(화면/음성/모션)이고 props 24개가 얽혀 있습니다(1차 보고서 9단계). **이번 단계에서 이 리팩터를 합니다.** 아래 Phase 2를 보세요.
4. **② 구간 후보:** `Highlight` 모델과 `HighlightList.tsx`에 **점수(`score`)가 이미 있습니다.** 새로 만드는 것은 **여러 개 선택 → 한 번에 생성**, **후보별 이유 한 줄**, 9:16 카드 레이아웃입니다.

## 전체 흐름

```
① 소스 입력 ─→ ①-b 분석 대기 ─┬─(유튜브·MP4)→ ② 구간 후보 비교 ─────────────┐
                               └─(블로그·상품)→ ③ 사진 선택 → 대본(블로그 3안 / 상품 셀링포인트) ┤
                                                                                 ↓
                                       ④ 템플릿 갤러리 → ⑤ 장면 편집기 → ⑥ 완료·업로드
                                                                                 ↓
                                                  ⑥-b 내 쇼츠(허브) ⇄ ⑨-b 원본 상세
```

### 소스별 단계 매트릭스 (⑦)
| 소스 | ①-b 대기 | ② 구간 후보 | ③ 사진 | 대본 | ④ 템플릿 | ⑤·⑥ |
|---|---|---|---|---|---|---|
| 유튜브 | 2~3분 | **필수** | 없음 | 자막 교정만 | 필수 | 전체 |
| MP4 | 업로드 + 2분 | **필수** | 없음 | 자막 교정만 | 필수 | 전체 |
| 블로그 URL | 1분 40초 | 없음 | **필수** | **3안 선택** | 필수 | 전체 |
| 상품 URL | 1분 20초 | 없음 | **필수** | **셀링포인트 3개 편집** | 필수 | 전체 |

**원칙:** 플로우가 갈라져서 새로 생기는 화면은 **"구간 후보(②)"와 "셀링포인트"** 두 개뿐입니다. ①-b는 문구만 바꿔 공유하고, ④·⑤·⑥은 완전히 공유합니다.

소스별 ①-b 단계 문구(그대로 쓰세요):
- 유튜브: 원본 영상 가져오기 → 말소리 받아쓰기 → 볼 만한 구간 고르기 → 후보별 자막 붙이기
- MP4: 파일 올리는 중(% 표시) → 말소리 받아쓰기 → 볼 만한 구간 고르기 → 후보별 자막 붙이기
- 블로그: 글 읽기 → 쓸 만한 사진 찾기 → 대본 3안 쓰기 → 나레이션 듣기
- 상품: 상품 정보 읽기 → 상품 사진 모으기 → 셀링포인트 찾기 → 나레이션 듣기

소스별 고유 옵션:
- 유튜브: 화자 추적 확대 · 무음 구간 제거 · 원본 음성 유지 / TTS로 덮어쓰기 · 9:16 크롭 위치
- MP4: 업로드 재개 · 긴 파일 백그라운드 처리 · 원본 보관 기간 안내. 원본이 이미 세로면 크롭 단계를 건너뜁니다
- 블로그: 사진 부족 시 스톡 보충 · 글 길이에 따라 1편 또는 시리즈 3편 · "블로그 글로 잇기" 교차 진입
- 상품: 가격·할인율 배지 자동 삽입 · 설명란에 상품 링크 자동 첨부 · 커머스 템플릿(가격 강조형)

- **왼쪽 순서:** eyebrow "쇼츠 만드는 중"(11px/700, letter-spacing .09em, `#8B8B98`) → 제목 22px/700 흰색 → 단계 4줄(아이콘 22px 원: 완료 `#0F7B52` 체크 / 진행 `#8b7cff` / 대기는 1.5px 테두리 + opacity .45, 오른쪽에 걸린 시간 11.5px `#63636f`) → 진행 바(6px, 트랙 `#26262f`, 채움 `#8b7cff`) + "1분 12초 지남 · 약 40초 남음" → **"먼저 찾은 구간" 카드**(`#1a1a21`, 1px `#26262f`)

### ② 구간 후보 비교 (신규 — 유튜브·MP4만)
- **목적:** 긴 영상에서 쇼츠로 쓸 구간을 **여러 개** 고릅니다.
- **레이아웃:** 카드 안에 제목 "하이라이트 후보 N개를 찾았어요" + 오른쪽에 원본 정보(12px muted). 3열 그리드(gap 10), 각 후보 카드는 9:16 썸네일 + 제목 한 줄(12px/600) + 이유 한 줄(10.5px).
- **후보 카드:** 왼쪽 위 점수 배지("92점 · 최고"는 accent 배경 흰 글씨, 나머지는 `#F0F0F3`/`#6B6B75`), 오른쪽 아래 길이(0:42). 선택되면 1.5px accent 테두리 + `--accent-soft` 배경.
- **하단 바:** "**N개** 선택됨 — 선택한 후보마다 쇼츠가 하나씩 만들어집니다" + primary "선택한 구간으로 계속"(높이 44). **예상 차감 박스**(⑨-e)를 여기에 함께 둡니다.
- **동작:** 여러 개 선택 가능. 남은 크레딧을 넘는 후보는 회색 처리하고 선택을 막습니다. 계속을 누르면 **선택한 후보마다 Clip을 하나씩** 만들고 ④로 갑니다(템플릿은 전체에 한 번만 고릅니다).
- **백엔드:** `Highlight`에 `reason`(짧은 이유 문자열)을 추가하세요. 여러 클립을 한 번에 만드는 엔드포인트가 필요합니다. 예: `POST /videos/{id}/clips:batch {highlight_ids[], template_id}`
- **파일:** `HighlightList.tsx`, `YoutubeClipFlow.tsx`, `YoutubeConfirmStep.tsx`, `highlight_service.py`, `api/clips.py`

### ③ 사진 선택 — 변경 없음 (1차 4단계 그대로)

### 셀링포인트 (신규 — 상품만)
목업에는 없습니다. 블로그의 "대본 3안" 자리에 들어가는 화면입니다. 셀링포인트 3개를 **편집 가능한 한 줄 입력칸**으로 보여주고, 가격·할인율·리뷰 수를 칩으로 보여줘 켜고 끌 수 있게 합니다. 레이아웃은 `ScriptToneStep`의 하단 고정 액션 바를 그대로 씁니다.

### ④ 템플릿 갤러리 (신규 독립 단계 — **최우선**)
- **목적:** 쇼츠의 인상을 정하는 가장 중요한 결정입니다. 지금 편집기 우측 패널에 흩어져 있는 자막 스타일을 **편집 전 단계**로 끌어올립니다.
- **레이아웃:** 카드 안 2열 그리드 `1fr 240px`, gap 20.
  - 왼쪽: 카테고리 칩(전체 12 · 임팩트 · 뉴스형 · 미니멀 · 브랜드 커스텀, 높이 30 pill, 선택은 ink 배경 흰 글씨) → 4열 템플릿 그리드(gap 10). 카드마다 9:16 미리보기 + 이름(11px). 선택은 2px accent 테두리 + 오른쪽 위 18px 체크 원.
  - 오른쪽: "미리보기 · {이름}" 라벨 + **큰 9:16 미리보기**(실제 자막 스타일 적용, 가능하면 Remotion 프리뷰) + primary "이 템플릿으로 계속"(높이 44, 전체 폭)
- **목업의 12종:** 임팩트 옐로우 · 클린 미니멀 · 뉴스 자막 · 화이트 박스 · 바이럴 레드 · 네온 그린 · 캡션 필 · 사이드 바 · 상단 헤드라인 · 아웃라인 · 그라디언트 바 · 커머스 가격형. 11번째 이후 마지막 칸은 **"내 브랜드 만들기"** 점선 칸이고, ⑨-a와 연결됩니다.
- **정렬:** 채널 연동 전에는 "많이 쓰는 순", 연동 뒤에는 "내 채널 평균 N배" 배지(⑨-f).
- **데이터:** 현재 `SubtitleTemplate`(font_size·색 3종·bold·outline·shadow·margin_v·border_style)로는 **위치(상단/하단)·배경 모양(박스/pill/사이드 바/그라디언트)·등장 애니메이션·강조색·카테고리·썸네일**을 표현할 수 없습니다. 컬럼을 추가하세요: `category`, `position`, `box_style`, `accent_color`, `animation`, `font_family`, `preview_url`, `is_system`. Remotion `BlogShorts.tsx`가 이 값을 읽어야 합니다.
- **파일:** 새 `TemplateGalleryStep.tsx`, `TemplatePanel.tsx`(편집 기능은 ⑤로 이동), `api/templates.py`, `template_service.py`, `remotion/src/BlogShorts.tsx`, `remotion/src/types.ts`, `lib/styleOverlay.ts`

### ⑤ 장면 편집기 (Phase 2 — 우측 패널 5탭 리팩터)
- **레이아웃:** 헤더 50px(← · 제목 15px/700 · "자동 저장됨" · 오른쪽 "31초 · 5장면" + primary "이 구성으로 영상 만들기") / 본문 3열(장면 목록 92px · 중앙 미리보기 `--page-bg` · 우측 패널 300px) / 하단 트랙 영역(`--surface-2`).
- **우측 패널 탭**(높이 26 세그먼트, 선택은 ink 배경):
  1. **텍스트**(선택한 장면): 자막 문장 · 폰트(`shortsFonts.ts`, `FontRolePicker`) · 크기(숫자) · 강조색 스와치 4개 + 직접 입력 · 등장 애니메이션(글자 튀기기 / 페이드 / 없음)
  2. **나레이션**(선택한 장면): TTS 보이스 · 속도 · 이 장면만 다시 듣기 · 원본 음성 유지(유튜브·MP4)
  3. **배경음악**(영상 전체): 무드별 트랙(`bgmMoods.ts`) · 볼륨 · 나레이션이 나올 때 자동 줄이기
  4. **구간편집**(선택한 장면): 장면 길이 · 시작/끝 트림 · 장면 전환
  5. **전체 스타일**(영상 전체): ④ 템플릿 값을 영상 전체에서 덮어쓰기(폰트·강조색·전환·워터마크)

- **상속 규칙:** 템플릿(④) → 전체 스타일 → 장면별 값 순서로 덮어씁니다. 장면에서 바꾼 값에는 "되돌리기" 링크를 둡니다.
- **리팩터:** `MediaPanel`의 props 24개를 **scene 단위 상태**와 **clip 단위 상태**로 나누세요. 예: `useSceneDraft(sceneId)` / `useClipStyle(clipId)`. 기존 3탭(화면/음성/모션) 컴포넌트는 새 5탭 안으로 옮기면 됩니다.

- **1차 출시는 다운로드만 합니다.** 채널 행은 feature flag 뒤에 두세요(⑨-f 단계 계획).

### ⑥-b 내 쇼츠 (허브) — `ProjectsPage.tsx`

- **완성:** **원본 단위로 묶습니다.** 원본 헤더(썸네일 30 · 제목 · "쇼츠 3편" 배지 · "유튜브 원본 · 9월 1일") 아래 6열 9:16 그리드("1편 · 0:42")

### ⑨-a 내 브랜드 (신규)
- 2열 `1fr 200px`. 왼쪽: 브랜드 이름 + "기본 브랜드" 배지 · 로고/워터마크(위치: 우하단/좌상단/숨김) · 브랜드 색 3개 + 추가 · 자막 폰트 · 기본 나레이션 · 끝인사 고정 문구(마지막 장면에 자동 삽입) · "브랜드 저장". 각주 "지금까지 만든 쇼츠에는 소급 적용하지 않습니다". 오른쪽: 적용 미리보기.
- 블로그 생성기의 "말투"와 같은 층위의 **계정 자산**입니다. 좌측 레일 항목과 ④ 마지막 슬롯에서 들어옵니다.
- **백엔드:** 새 테이블 `brand_presets(user_id, name, logo_path, watermark_pos, colors_json, font_family, voice_id, outro_text, is_default)`

### ⑨-b 원본 상세 · 일괄 관리 (신규)
- ⑥-b에서 원본을 누르면 들어옵니다. 헤더(← · 원본 제목 · "유튜브 원본 24:10 · 쇼츠 5편" · outline "+ 이 원본에서 더 만들기") + 5열 9:16 그리드.
- 편별 상태 배지: 완성 0:42(녹색) · 만드는 중 68%(accent) · 대기 중(amber) · 실패 · 다시(danger, 썸네일 `#F7E7E5` + "!")
- 체크박스로 여러 편 선택 → **아래 플로팅 바**(ink 배경, radius 13, 그림자 `0 12px 30px rgba(22,22,26,.32)`): "N편 선택됨" | 한꺼번에 다운로드 · 예약 업로드 · 템플릿 일괄 변경(0회 차감)

### ⑨-c 실패·예외 상태
**공통 규칙:** ① 무슨 일이 있었나 ② 무엇을 하면 되나 ③ 크레딧은 어떻게 되나를 답합니다. **실패 시 크레딧은 항상 자동 복구하고 문구에 밝힙니다.** 복구 버튼은 최대 2개입니다. 서버 원문은 `RenderSpecFooter` 접힘 영역에만 둡니다.

| 상황 | 제목 | 버튼 | 톤 |
|---|---|---|---|
| 렌더 폴백 | 간단 버전으로 만들어졌어요 | 스타일 적용해서 다시 만들기 | amber |
| 비공개·삭제 영상 | 이 영상은 가져올 수 없어요 | 다른 링크 넣기 · 파일로 올리기 | danger |
| 저작권 음원 감지 | 원본에 저작권 있는 음악이 있어요 | 무료 음원으로 교체 · 그대로 두기 | amber |
| 크레딧 소진 | 이번 달 크레딧을 다 쓰셨어요 | 플랜 올리기 · 크레딧 추가 구매 | neutral |

본문 카피는 목업 ⑨-c를 그대로 쓰세요. amber = 배경 `#FDF9EE` / 테두리 `#F0DFB4` / 글자 `#8A6410`, danger = `#FDF6F5` / `#F0C9C5` / `#C2453C`.

### ⑨-d 모바일 (3화면, 폭 ≤ 640px)
- **포함:** 시작(큰 primary 카드 "유튜브 링크 넣기" + 보조 48px 버튼 2개) · 진행(①-b 다크, "다 되면 알림 보낼게요") · 완료("N편 모두 저장" 56px primary + "유튜브에 바로 올리기")
- **제외:** ④ 템플릿 커스텀, ⑤ 편집기. ②와 ④는 모바일에서 **AI 추천값으로 자동 진행**하고 "PC에서 바꾸기" 안내를 보여줍니다.
- 탭 대상 최소 48px, 주 CTA 56px, 하단 탭 바(홈 · 내 쇼츠 · 설정)

## ⑨-e 크레딧 — 코드 기준 제안
현재 쇼츠 한도(Free 3 / Lite 20 / Pro 80, 렌더 완료 시 1 차감)는 그대로 둡니다. **소스별 부담 차이만 반영합니다:**

| 작업 | 차감 (쇼츠 크레딧) |
|---|---|
| 블로그·상품 → 쇼츠 1편 | 1 |
| 유튜브·MP4 → 하이라이트 쇼츠 1편 | 1 |
| 긴 영상 분석 | 무료 (단, 플랜별 `max_video_minutes` 10/30/120 적용) |
| 템플릿·스타일 재생성, 장면 편집 후 재렌더, 실패 재시도 | 0 |

- **차감 시점은 렌더 성공 시점입니다**(현행 유지). 실패하면 차감하지 않습니다.
- 목업의 "5분당 1회 분석 비용"은 **보류합니다.** 도입하려면 정책을 따로 결정해야 합니다.
- **예상 차감 박스**는 ①(CTA 옆, 1차 8단계에 이미 있음)과 ②(선택 개수 × 1)에 둡니다. 남은 수를 넘는 선택은 막습니다.
- 추가 구매(10편 충전권)는 결제 연동이 필요하므로 UI만 feature flag 뒤에 두세요.
- 지갑 위젯: 상단 바 `StudioShell`에 이미 있는 게이지를 유지합니다. 블로그 포스트는 `ditodio_linked`일 때 별도 행으로 보여줍니다(현행).

## ⑨-f 성과 피드백 (Phase 4)
대시보드는 만들지 않습니다. 조회수는 ④ 템플릿 배지("내 채널 평균 2.3배", 5편 이상 올린 뒤부터) · ⑥-b 카드("▲ 4,820회 · 7일") · 월초 이메일(블로그 리포트와 한 통) 세 곳에만 되돌립니다. 유튜브 Data API는 심사가 필요하고, 인스타는 비즈니스 계정만 됩니다.

## 구현 단계 (권장 순서)
각 Phase가 끝날 때마다 `npm run build`와 `pytest -q`를 통과시키고, Phase마다 커밋을 나누세요.

**Phase 1 — 템플릿 (최우선, 약 1~1.5주)**
1. `SubtitleTemplate` 스키마 확장 + 마이그레이션 + 시스템 템플릿 12종 시드
2. Remotion `BlogShorts.tsx`에서 position / box_style / accent / animation / font_family를 렌더
3. `TemplateGalleryStep.tsx`를 만들고 모든 소스 플로우에서 편집기 앞에 넣기
4. 템플릿 썸네일 생성(Remotion still 또는 정적 이미지)

**Phase 2 — 편집기 5탭 (약 1.5~2주, 리팩터 위험 큼)**
1. `MediaPanel` 상태를 scene / clip 단위로 분리(동작 변화 없이 먼저 커밋)
2. 5탭 UI + 하단 트랙 3줄
3. 텍스트 효과(폰트·크기·강조색·애니메이션)를 장면 단위로 저장하고 Remotion에 반영
4. 상속 규칙과 "되돌리기"

**Phase 3 — 소스별 플로우 + 대기 + 허브 (약 1.5주)**
1. ① → ②/③ 분기 정리, 상품 셀링포인트 화면
2. ② 다중 선택 + 일괄 생성 API + `Highlight.reason`
3. ①-b 소스별 문구 + stage 이벤트 + 먼저 찾은 구간 표시
4. ⑥-b 원본 그룹핑 · ⑨-b 원본 상세 · 일괄 작업 바
5. ⑨-c 에러 카피 표 적용(에러 코드 → 카피 매핑 테이블)

**Phase 4 — 계정 자산 · 모바일 · 연동**
1. ⑨-a 내 브랜드(테이블 + 화면 + 템플릿·렌더 적용)
2. ⑨-d 모바일 반응형 3화면
3. ⑥ 채널 연결 · 예약 업로드(유튜브 먼저) → ⑨-f 조회수 회수
